# DONATY-U — Backend API

API para gestión de donaciones con roles (admin, donante, recolector), pagos con Stripe, chat en tiempo real, IA y dashboard de estadísticas.

---

## Tecnologías
- Node.js, Express
- MongoDB + Mongoose
- JWT + bcrypt
- Nodemailer
- Passport (Google OAuth)
- Stripe
- Socket.IO
- Hugging Face (IA)

---

## Requisitos
- Node 20+
- MongoDB local o remoto
